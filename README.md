# ركضتك (Rakdatak)

تطبيق Android + Wear OS لتدريب المبتدئ من الصفر حتى يحقق الهدفين معًا:

- ركض 5 كم
- ركض 30 دقيقة متواصلة

الخطة الأساسية 8 أسابيع، لكنها تكيفية ويمكن أن تمتد أو تتسارع حسب الالتزام، الأداء، نبض القلب، والألم بعد التمرين.

## مبادئ المشروع

- العربية هي اللغة الأساسية، والإنجليزية لغة ثانية اختيارية.
- Android وWear OS فقط؛ لا يوجد دعم Apple Watch.
- مجاني بالكامل وبدون إعلانات، مع دعم اختياري عبر PayPal مستقبلًا.
- يعمل أثناء التمرين بدون إنترنت، ثم يزامن البيانات عند عودة الاتصال.
- الهاتف والساعة يمكن أن يديرا التمرين، والساعة تستطيع تنفيذ التمرين وحدها عند توفر الحساسات.
- Samsung Health وHealth Connect ضمن أولويات التكامل.

## الحالة

المشروع في مرحلة التأسيس الأولى.
